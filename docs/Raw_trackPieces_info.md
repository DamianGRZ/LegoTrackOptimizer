Set 210.1 - Double Crossover - Outside

Introduction



Set 210.1 is a double crossover with all the ground throws on the outside. It's equivalent to the discontinued LEGO® set 7996.

Features

There are a few significant improvements compared to the LEGO® 7996:

The crossover is modular, it consists of 6 track parts that can be used to build different types of switches.



The 4 switches of the crossover are independent, this means that two trains can pass the crossover simultaneously.

All our switches have a spring mechanism so trains can pass even if the switch is not in the 'correct' position. They have a LEGO® style ground throw so they will blend in seamlessly with your other switches. The switches are also fully compatible with our track switch motors, so this double crossover can easily be motorized.

Dimensions

The double crossover is designed to be fully compatible with the LEGO® grid. It fits into layouts that have parallel tracks spaced at an 8 stud distance.
