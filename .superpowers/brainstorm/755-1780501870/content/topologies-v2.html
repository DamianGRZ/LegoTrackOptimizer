Three buildable closed loops (R40 turns only, rounded everywhere)

Pick the one to pursue. Blue = track, green Y = switch, red ✕ = CROSS_90, orange ▭ = DOUBLE_CROSSOVER. All are single closed circuits.

A · Concentric spiral (S-bend steps) ★ densest

One path spirals inward, each lap stepping ~8 studs closer via an S-bend (no U-turn, so it packs tight). Corners are R40 quarter-arcs. ~5 rings use all 80 R40 + most straights → ~85–95%. Closes planar — no crossing needed. The one tricky bit is linking the innermost lap back out to the outer (a short ramp, or 1 CROSS_90 cutting straight out).

B · Serpentine + CROSS_90 return

Horizontal lanes snaked together; the return spine cuts straight back across the lanes at 90° (CROSS_90). But the R40 U-turns force lanes 80 studs apart, so only ~5 lanes fit and density is ~65–75% — and the return crosses ≤2 lanes (only 2 CROSS_90). Uses crossings, but pays for it in sparseness.

C · Stacked loops + DOUBLE_CROSSOVER

Two (or three) parallel oval loops; a DOUBLE_CROSSOVER weaves them into one circuit — exactly what the DC piece is for. Cleanest closure and the most natural crossing use, but only 2–3 loops stack, so ~65–80%. Less dense than A, but geometrically the safest and it actually consumes the DC.

Honest read: A (spiral) wins on raw density and is what gets you toward 90%; crossings there are optional polish. B and C guarantee the crossing pieces get used but cap lower. Since the goal is max utilization, I lean A — and we bolt a small DC/CROSS weave onto it later for the last couple %. Which do you want?
